# comms.io data branch

This branch is generated by the archiver on `master`. Do not edit it by hand.

- `manifest.json` is the source of truth for table files, row counts, and checksums.
- `schema.json` describes the Parquet columns and query hints.
- `state/` contains the chunked SQLite working database used by Colab.
- The site reads this branch through raw.githubusercontent.com.

Images, raw HTML, and per-artist JSON are intentionally not stored here.
The website loads the manifest and queries the Parquet files with DuckDB-WASM.
